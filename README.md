# 🚀 Portfolio — Ibrahim Rahmani

Un portfolio personnel moderne et responsive, conçu pour présenter mes projets, compétences et expériences en tant que développeur.

---

## ✨ Aperçu

Ce portfolio est une application web développée avec les technologies front-end les plus actuelles, offrant une interface fluide, rapide et élégante.

---

## 🛠️ Technologies utilisées

| Technologie | Rôle |
|---|---|
| **React** | Framework UI |
| **TypeScript** | Typage statique |
| **Vite** | Bundler / dev server ultra-rapide |
| **Tailwind CSS** | Styling utilitaire |
| **shadcn/ui** | Composants UI accessibles |
| **ESLint** | Linting & qualité de code |
| **Django REST Framework** | API des projets et articles |
| **PostgreSQL (Neon)** | Base de données de production |

## 🚀 Démarrage rapide

### Prérequis

- [Node.js](https://nodejs.org/) v18+
- [npm](https://www.npmjs.com/) ou [bun](https://bun.sh/)

### Installation

```bash
# Cloner le dépôt
git clone https://github.com/ibrahimrh555/Portfolio_Ibrahim_Rahmani.git

# Aller dans le répertoire
cd Portfolio_Ibrahim_Rahmani

# Installer les dépendances
npm install
# ou avec bun
bun install
```

### Lancer en développement

```bash
npm run dev
# ou
bun run dev
```

L'application sera accessible sur [http://localhost:5173](http://localhost:5173)

### Build pour la production

```bash
npm run build
# ou
bun run build
```

### Prévisualiser le build

```bash
npm run preview
```
